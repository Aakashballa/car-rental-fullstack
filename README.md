# 🚗 Car Rental Full Stack App

A full-stack **Car Rental Web Application** built using Flask, SQLite, and HTML/CSS.  
This project simulates a real-world booking platform with user and admin functionality.

---

## ✨ Features

### 🧑 User Features
- User Registration and Login
- Browse available cars by category
- Book cars with location and date
- View booking history
- Cancel bookings

### 👑 Admin Features
- Admin login system
- Add new cars
- Edit existing car details
- Delete cars
- Toggle car availability
- View recent bookings

---

## ⚙️ Advanced Features

- ✅ Booking conflict detection (prevents overlapping bookings)
- ✅ Date-based price calculation
- ✅ Role-based access (User/Admin)

---

## 🛠️ Tech Stack

- Backend: **Flask (Python)**
- Database: **SQLite**
- Frontend: **HTML, CSS, Jinja Templates**
- ORM: **SQLAlchemy**
